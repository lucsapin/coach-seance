# Coach Séance 💪

Suivi de séance full body (kettlebell + poids du corps) avec chrono intégré.

Sert à la salle, depuis l'écran d'accueil d'un iPhone.

## Séances

- **Séance A** : squat goblet, pompes, rowing 1 bras, fentes, gainage, élévations
- **Séance B** : swing, développé militaire, tractions/rows, squats bulgares, gainage latéral, curl/triceps

Format : supersets alternés, 30 min par séance, 2x/semaine.

## Site

Disponible sur GitHub Pages : https://lucsapin.github.io/coach-seance/

## Installation sur iPhone

Ouvrir le site dans Safari, bouton Partager, puis "Sur l'écran d'accueil". L'application s'ouvre en plein écran, sans barre de navigation.
